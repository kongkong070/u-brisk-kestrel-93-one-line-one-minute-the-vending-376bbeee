## Entry

> Hey — I've been humming your name all day. Press B7 and I'll drop something sweet, because you're the only exact change I need.

One pickup line, 200 characters at most, spoken by a vending machine to a
passing human. `main.ts` (Node 22 stdlib only) writes it to
`/output/entry.txt` and validates it against the gate (1–200 characters,
not only whitespace, single line) before writing.
